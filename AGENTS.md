# Shared AI workbench instructions

- Confirm which project/repository is the target before editing.
- Keep project-specific work isolated in that project's repository.
- Never read, print, commit, or transmit secrets (.env files, tokens, keys, cookies).
- Prefer small, reviewable changes; inspect diffs and run project tests where possible.
- Do not publish/deploy or merge without the user's explicit instruction.
- Report concrete completed work, checks run, blockers, and the next required user action.
- Do not claim a tool was installed or a process is running unless that was verified.
